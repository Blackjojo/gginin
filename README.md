# Slotgame 開案企劃 Skill

本倉庫收錄可重複使用的 Slotgame 開案企劃流程 Skill。流程涵蓋玩法討論、規則鎖定、數學交接，以及企劃書、簡報、流程圖與玩家規則的同步交付。

## 安裝到 Codex

將 [`skills/slotgame-opening-proposal-workflow`](skills/slotgame-opening-proposal-workflow) 整個目錄複製到本機 `~/.codex/skills/`，保留 `SKILL.md`、`agents/` 與 `references/` 的相對位置。

安裝後，在對話中使用：

```text
$slotgame-opening-proposal-workflow 幫我從概念開始規劃一款 Slotgame。
```

## 使用範圍

- 預設以繁體中文工作，依「概念 → 單項討論 → 明確鎖定 → 文件同步」推進。
- 規劃目標與待數學驗證的數值，不能當成已驗證結果。
- 每個新專案都應以自己的規格與決策紀錄為準，不套用其他遊戲的機制或數值。

完整規則見 [`SKILL.md`](skills/slotgame-opening-proposal-workflow/SKILL.md)。
