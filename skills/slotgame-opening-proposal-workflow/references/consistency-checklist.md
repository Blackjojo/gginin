# 開案交付一致性檢核

## 規則層

- 盤面尺寸、連接方向、最低成群數在所有文件一致。
- 初始判定、消除、掉落、補牌、特殊符號生成與再判定順序一致。
- Wild 的代替範圍、生成顆數、倍數合併與保留範圍一致。
- Scatter 的出現位置、觸發數量、固定獎與 Retrigger 一致。
- Main Game、自然 FG、Buy FG 的差異逐項寫清楚。
- 升級進度在無得分、跨 Spin、加局及重進 Feature 時的行為一致。
- Max Win、功能結束與中斷連線處理有單一口徑。

## 計分層

- 每個公式定義輸入單位，避免混用 Bet、Coin、Credit、Pay 倍數與賠率。
- 多得分群、多 Wild、多 Scatter 與倍數池的加總順序明確。
- 所有案例逐步相加後等於最終總分。
- 自然 FG 進場固定獎沒有誤套到 Buy FG。
- 即時倍數與最終倍數池派彩沒有重複或漏算。
- RTP、Hit Rate、Feature 頻率、平均回收與封頂率附版本與樣本證據；否則標記為目標。
- 表面賠率已換算成實際 Bet 倍數，且所有案例使用同一派彩單位。
- 自然 Feature RTP 可由觸發率乘平均派彩回算，Feature Buy RTP 可由平均派彩除以價格回算。
- Hit Rate 分母、Feature 子局、Trigger 與一般得獎重疊方式在企劃、數學與報表一致。
- 倍率「到達」與「實際套用」沒有混寫。
- 超額截斷或重抽的判定範圍、最大次數、終止條件與稽核欄位完整。
- 取整、上限與重抽後，各投注級距的最終 RTP 已分開驗證。
- 波動標籤與 Feature RTP 占比、等待機率、短期報酬及尾部獎金相符。

## 文件層

- 封面、頁首頁尾、檔名與內文版本一致。
- 舊遊戲名稱、舊 Symbols、舊公式與已廢棄流程已移除。
- DOCX 表格無截字、跨頁錯位或孤立標題。
- PPTX 文字未溢出，圖表與流程線不遮擋方塊。
- Draw.io 保留可編輯來源；Axure 使用 SVG／PNG 時標明不可轉為原生元件。
- 玩家 Help 不含權重、RTP 調參、強制腳本、封包上限或其他內控資訊。
- 繁中、簡中、英文的數字、功能名稱與觸發條件一致。

## 來源同步層

- 生成腳本與生成輸出同時更新。
- 重建後不會恢復舊規則。
- 流程圖、企劃書、簡報、Help、UI 規格與 QA 案例引用同一規則版本。
- 數學模型、設定檔與測試對應目前規則。
- 未決問題集中列出，沒有散落在不同文件中的隱性假設。
- 公式、Bet 單位、Paytable 解讀、上限或重抽規則變更後，舊模擬、舊案例與舊玩家文案已標記失效或更新。
